# 公開までの手順（T027〜T030）

**この4つは、ユーザー自身の手元でしかできません。** Cloudflare のアカウントに
ログインする必要があり、そのログインは AI 側からは行えないためです。

**上から順に、1つずつ実行してください。**「>」で始まる行がパソコンに打ち込む文字です。
打ち込んだあと Enter を押します。

**先に読んでおくこと**

- **本物の顧客の情報を入れるのは、いちばん最後（T030）です。** その前に T028
  （自分以外は開けないようにする）を必ず終えてください。ネット上に置いた画面は、
  アドレスを知られただけで誰でも開けます
- 途中で分からなくなったら、そこで止めて画面をそのまま見せてください。
  進めてしまうより、止まって聞くほうが安全です

---

## 準備（1回だけ）

手元のパソコンに、この仕組みの一式と、動かすための道具を用意します。

1. **Node 22 を入れる** — https://nodejs.org/ から「LTS」と書かれたものを入れます
2. **pnpm を入れる**

   ```
   > npm install -g pnpm
   ```

3. **この仕組みを手元に持ってくる**

   ```
   > git clone https://github.com/rahiseko-alt/ex1.git
   > cd ex1
   > pnpm install
   ```

## T027 ネット上に置いて、自分の端末から開けるようにする

### 1. Cloudflare のアカウントを作る

https://dash.cloudflare.com/sign-up でメールアドレスとパスワードを登録します。
**[曖昧] 登録の途中でクレジットカードを求められるかは未確認です。** 求められた場合は
そこで止めて、画面を見せてください。

### 2. 無料でどこまで使えるかを確かめる

**[曖昧] 無料の範囲は変わることがあるため、実際の画面で確かめてください。**
Cloudflare の画面で Workers と D1 の料金のページを開き、「1日あたり何回まで無料か」を
見てください。数字を控えて、私に教えてもらえれば、足りるかどうかを一緒に判断します。

### 3. パソコンと Cloudflare をつなぐ

```
> npx wrangler login
```

ブラウザが開くので「Allow（許可）」を押します。

### 4. ネット上に顧客データの置き場を作る

```
> npx wrangler d1 create crm
```

実行すると、画面に次のような文字が出ます。

```
database_id = "12345678-abcd-..."
```

**この `database_id` の中身（引用符の中）を控えてください。**

### 5. 控えた値を設定ファイルに書く

`wrangler.toml` をテキストエディタで開き、

```
database_id = "local-only-placeholder"
```

の行を、控えた値に差し替えます。

```
database_id = "12345678-abcd-..."
```

**ここを直し忘れると、公開した画面から顧客データが見つかりません。**

### 6. ネット上の置き場に表を作る

```
> pnpm run db:setup:remote
```

### 7. 公開する

```
> pnpm run deploy
```

最後に `https://crm.〇〇〇.workers.dev` のようなアドレスが出ます。**これを控えてください。**

### 8. 確かめる

パソコンを閉じた状態で、スマホのブラウザからそのアドレスを開きます。
顧客の一覧が出れば T027 は完了です。

## T028 自分以外は開けないようにする

**T027 が終わった直後に、続けてこれをやってください。** この時点では、アドレスを
知っている人なら誰でも開けます。

Cloudflare の「Zero Trust」の画面で、公開したアドレスに「メールに届いた番号を
入れないと開けない」鍵をかけます。**[曖昧] 画面の名前や場所は変わることがあるため、
手順を1つずつ書き下すことはしていません。** Cloudflare の画面を開いたところで
スクリーンショットを見せてください。その画面に合わせて、どこを押すかをお伝えします。

確かめ方: 普段使っていないブラウザ（またはシークレットウィンドウ）で公開アドレスを
開き、顧客の情報が見えずログインを求められること、自分のメールに届いた番号を入れると
一覧が開くことを見ます。

## T029 消えたときに戻せることを試しておく

**本物の顧客を入れる前に、必ず一度試してください。** 控えの取り方が間違っていることは、
実際に戻すまで分かりません。

1. 公開した画面で、お試しの顧客を3人ほど登録する
2. 一覧の「書き出し」を押して、ファイルを手元に保存する
3. **試し用の置き場を空にする**（本番の置き場ではなく、手元の `pnpm run db:setup` で
   作った置き場で試してください。手順は私に聞いてください）
4. 「取り込み」で、保存したファイルを選ぶ
5. 3人が全員そろって戻っていることを確認する

## T030 実際の顧客を入れて一周使ってみる

**T028 が終わっていることを必ず確かめてから。**

1. 実際の顧客を5件登録する
2. そのうち1件に、やり取りと案件を入れる
3. 数日、実際の記録に使ってみる
4. 使ってみて足りないもの・使いにくいところを教えてください。次の計画に足します
